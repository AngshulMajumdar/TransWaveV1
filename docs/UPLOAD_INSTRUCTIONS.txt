TRANSWAVE GITHUB PAGE

1. Copy the included `docs` directory into the root of:
   https://github.com/AngshulMajumdar/TransWaveV1

2. In GitHub, open:
   Settings -> Pages

3. Under Build and deployment choose:
   Source: Deploy from a branch
   Branch: main
   Folder: /docs

4. Save. The page will be served at:
   https://angshulmajumdar.github.io/TransWaveV1/

5. Medium import:
   In Medium choose "Import a story" and enter the GitHub Pages URL above.

The page is deliberately static: no JavaScript, no build system, and all images use relative paths so it can be served directly by GitHub Pages.
